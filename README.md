# ExamHero Pro
Exam practice app for Nigerian students (WAEC, NECO, JAMB).

## Putting it on GitHub (important)
1. **Unzip first.** GitHub does not open zip files.
2. Upload the CONTENTS of the unzipped `examhero-pro` folder (not the zip itself), keeping the folders: `src/`, `api/`, `public/`, `supabase/`, `docs/`, plus `index.html`, `package.json`, `vite.config.js`, `.gitignore`, `.env.example`.
3. Never upload a real `.env` file or secret keys.

- Start here: `docs/DEPLOY_GUIDE.md`
- Money plan: `docs/MONETIZATION.md`
- Edit settings at the top of `src/App.jsx`
- Server code (payments, AI, accounts check): `api/`
- Database: `supabase/schema.sql`
